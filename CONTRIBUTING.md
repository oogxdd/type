# Contributing

Thanks for helping improve Type. Keep changes focused and explain the user or operator problem they solve.

## Before opening a pull request

- Read `AGENTS.md` and the relevant documentation for the area you change.
- For behavior changes, add or update focused tests and run the checks required by the repository guidance.
- For documentation-only changes, review the rendered Markdown and run `git diff --check`.
- Keep Rust and TypeScript contracts aligned when changing shared behavior.
- Do not include credentials, private notes, user content, or unrelated generated artifacts.
- Describe any platform or release workflow you could not verify.

## Pull requests

Use the pull request template. Link related issues when useful, summarize user-visible changes, and list the checks you actually ran. Do not claim a platform build, release, or deployment was verified unless it was.
