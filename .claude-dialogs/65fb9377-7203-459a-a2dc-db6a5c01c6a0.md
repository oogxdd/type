## How it behaves

Type `mv ` (or run **"Move note to folder…"**) and the palette flips into a terminal-style folder picker that moves the **open note** (or the multi-selected notes):

- **`mv pe`** → fuzzy-matches *every* folder by name; `Personal` ranks first. Name matches across the whole tree, so `mv Health` surfaces both `Personal/Body/Health` and `Personal/Mental/Health` (full path shown on the right to disambiguate).
- **`mv personal/`** → drills in, listing the children of `Personal` (case-insensitive). Adds a **"Move into Personal"** row first, so you can drop the note in the folder itself *or* pick a subfolder.
- **`mv personal/me`** → filters children to `Mental`.
- **Tab** → completes the highlighted folder and appends `/`, so you keep navigating deeper (`mv Personal/` → Tab on Body → `mv Personal/Body/` …).
- **Enter** → moves into the highlighted folder.
- **`mv project_x/design/hud`** (doesn't exist yet) → offers **"Create & move to project_x/design/hud"** — missing folders are created (same as the old dialog).
- `/` leading/trailing slashes are tolerated, matching your `/project_x/design/hud` example.
