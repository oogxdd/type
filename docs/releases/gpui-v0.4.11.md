# Type 0.4.11

Native GPUI desktop release for macOS 12 or newer on Apple Silicon (M-series).

- Recordings: play audio above the note with pause, ±10-second seek and transcription status/progress.
- Transcription: synced recordings are queued automatically in Desktop routing mode; retranscribe one recording with AssemblyAI from Settings without changing the Whisper default.
- Whisper: choose a local model folder and check/set up the engine from Settings.
- Sync: phone pushes refresh the desktop immediately; faster incremental Git sync.
- Vim: half-page motions scroll only when the cursor leaves the viewport.

Built locally, signed with Developer ID, notarized by Apple and delivered through the native GPUI updater. Intel, Linux and Windows builds are not included in this release.
