# Type 0.4.8 — reliable new-note capture and navigation

- Cmd+N immediately creates a Stream note, selects it under Today and focuses the editor in Insert mode.
- New notes keep their editor focus and file identity through saves and background refreshes; sidebar titles update while typing.
- Background polling preserves manually scrolled navigation instead of jumping back to the selected folder.
- The line-number gutter keeps a stable width for notes with fewer than 100 lines.

Update through Settings → Updates → Check for updates.
