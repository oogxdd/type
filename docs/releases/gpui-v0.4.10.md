# Type 0.4.10

Native GPUI desktop release for macOS 12 or newer on Apple Silicon (M-series).

- Open ordinary folders as editable workspaces with compact folder tabs, text-file autosave, encoding preservation and protection against external changes. Includes the open-folders work through `dcb2b29b`.
- Improve sidebar controls, Stream filters and phone-sync status with a pairing QR on hover.
- Update navigation immediately after rename and deletion; simplify move-palette completion and deletion confirmation.
- Restore Vim undo/redo and add half-page movement.

Built locally, signed with Developer ID, notarized by Apple and delivered through the native GPUI updater. Intel, Linux and Windows builds are not included in this release.
