# Type 0.4.12

Native GPUI desktop release for macOS 12 or newer on Apple Silicon (M-series).

- Images: drop or paste an image into a note; it is saved to attachments and shown as a thumbnail.
- Folders: pin folders with `p`, Cmd+K or the context menu; pins sync across devices.
- Flags and tags: Cmd+K `fl <name>` / `tag <name>` toggle them on selected notes; new Reflections filter.
- Stream: Move to previous day / Move back to its day for late-night notes; the current week hides empty days.

Built locally, signed with Developer ID, notarized by Apple and delivered through the native GPUI updater. Intel, Linux and Windows builds are not included in this release.
