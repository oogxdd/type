# Type 0.4.9 — folders and daily Stream review

- Create empty folders from a folder’s right-click menu, inside that folder or at the root. The Folders root area also offers creation.
- File the focused Stream note with Cmd+K → `mv `: search folder names or type a relative path, use Tab/right arrow to complete, and Enter to move. Missing destination folders can be created as part of the move.
- Review one day in Stream using the filter menu → Review a day. Status and date filters are saved locally; Unreviewed hides both reviewed and archived notes.
- Cmd+K → Archive / unarchive or Mark / unmark reviewed updates the existing note marker and focuses the next visible note. Moving a Stream note advances focus too. Archived notes remain available through the Archived or All filters.
- Command palette opening no longer builds a command for every note. Move completion works for empty folders, and an empty filtered view no longer creates an unexpected note.

Update through Settings → Updates → Check for updates.
