# Type 0.4.5 — native macOS desktop

- Native GPUI desktop with a plain Markdown editor, Vim modes and Stream / Folders navigation.
- Settings for editor appearance, working folders, sync, security and imports.
- Current-line highlighting stays visible while typing and wrapping text.
- Signed native updates through Settings → Updates; notes are saved before restarting.

The first GPUI installation is a manual replacement of Type.app. Quit the
previous desktop shell before opening the same notes collection in GPUI.
Later native releases use the new updater. The previous Tauri updater does
not install GPUI builds.
