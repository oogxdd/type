# Mac: режим «бесогонка»

Статус: проект, 2026-09-17; не реализовано.
[Общий контракт и PANIC](BIOMETRIC_PANIC_UNLOCK.md).

## Пользовательский сценарий

Приложение и обычные заметки открываются без дополнительного запроса. При открытии
выбранной защищённой заметки её редактор заменяется экраном «Введите пароль».
Остальная обычная часть приложения не блокируется.

Клик по визуально невыделенной области или отправка короткой фразы запуска
показывает системный Touch ID. Только успешный доступ к ключу открывает защищённую
заметку. До явного действия Touch ID не запрашивается. Отмена, lockout и отсутствие
сенсора оставляют заметку закрытой; пользователь может вернуться к обычным заметкам.

Паник-фраза запускает локальный PANIC только для защищённого набора, без Touch ID
и подтверждения. Выбор «текущая или все защищённые заметки» ещё не сделан. Обычные
заметки и корни профилей не удаляются. Детали итогового экрана и стирания открыты.

## Нативная интеграция

Tauri/Rust вызывает нативный адаптер LocalAuthentication + Keychain. Ключ или обёртка
хранится с биометрическим ACL. Отдельный успешный `evaluatePolicy` с последующим
чтением незащищённого ключа недостаточен. Проверить Data Protection Keychain,
подпись, entitlements и поддерживаемые версии macOS.

Не разрешать пароль macOS, Apple Watch или ранее открытый сеанс ОС в качестве
замены требуемой биометрии. Политика `deviceOwnerAuthenticationWithBiometrics`
исключает обычный fallback на пароль устройства; ACL ключа должен ей соответствовать.
Точный набор флагов и отсутствие повторного использования прежней авторизации
проверить на устройстве. Без Touch ID не ослаблять защиту молча: recovery или отказ
от включения режима нужно определить до выпуска.

Приложение не получает отпечаток. Симметричный ключ из Keychain после авторизации
может находиться в памяти Rust; это не обещание, что он никогда не покидает Secure
Enclave. JS получает только состояние операции. Core выдаёт доступ к конкретной
заметке, а не глобально разблокирует все данные.

## Жизненный цикл и PANIC

Предложение: закрывать защищённую сессию при уходе из заметки, блокировке macOS,
уходе приложения в фон и завершении. В нескольких окнах скрыть все представления
соответствующей заметки. Собственный Touch ID dialog не должен ошибочно считаться
уходом в фон; проверить сон/пробуждение и смену фокуса Tauri.

PANIC отменяет авторизацию, инвалидирует сессии целевых заметок и выполняет общий
протокол. Поздний callback, autosave и background worker не могут восстановить
доступ или записать стёртые данные. Если репозиторий или сервер общий, временно
приостановить его, сохранив обычные данные. Удаление выбранного Keychain item без
Touch ID — обязательное проверяемое условие, если этот механизм войдёт в стирание.

Учесть внешние notes roots, plaintext exports, Finder/Quick Look, Git, Time Machine
и APFS snapshots. Существующие сторонние копии PANIC приложения не удаляет.

## Проверки на настоящем Mac

- Обычные заметки работают до и после открытия/стирания защищённых.
- Нет автоматической биометрии; оба выбранных маршрута запуска работают.
- Пароль macOS и отмена не открывают защищённую заметку.
- Несколько окон, поздние callbacks, фоновые workers и sync соблюдают scope.
- PANIC работает без отпечатка и сети; перезапуск не возвращает старую сессию.
- Release и isolated dev identifier не смешивают Keychain items и реальные данные.
- Смена биометрии/оборудования следует выбранной политике восстановления.
