```dart
class DirectionalHorizontalDragRecognizer extends HorizontalDragGestureRecognizer {
  DirectionalHorizontalDragRecognizer({
    super.debugOwner,
    this.verticalBailout = 8.0,
    this.horizontalCommit = 12.0,
    this.dominanceRatio = 1.2,
  });
  final Map<int, Offset> _travel = <int, Offset>{};

  @override
  void handleEvent(PointerEvent event) {
    if (event is PointerMoveEvent) {
      final Offset total = (_travel[event.pointer] ?? Offset.zero) + event.delta;
      _travel[event.pointer] = total;
      gestureDebug.axis.value = '${total.dx.toStringAsFixed(0)},${total.dy.toStringAsFixed(0)}';
      if (total.dy.abs() > verticalBailout &&
          total.dy.abs() > total.dx.abs() * dominanceRatio) {
        _travel.remove(event.pointer);
        resolve(GestureDisposition.rejected);   // concede to the scrollable
        return;
      }
      if (total.dx.abs() > horizontalCommit &&
          total.dx.abs() > total.dy.abs() * dominanceRatio) {
        resolve(GestureDisposition.accepted);   // acceptGesture replays pending offset
      }
    }
    super.handleEvent(event);
  }
}
```

## 5. Problem Solving

**Solved:** Flutter arena conflict (hit-test ordering); Flutter test harness velocity trap; RN asymmetric `horizontalVerdict` killing arcing swipe-ups; RN back-swipe being two implementations split by height; the demo banner swallowing swipe-up touches; the `node_modules` / Metro setup; the non-adaptive back swipe (Part A); the `manualActivation` blocker causing 2-in-10 horizontal swipe loss (Part B, diagnosed from the real Metro log).

**Diagnosed from the live `[gesture]` log** — the decisive evidence:
```
menu:begin
file:down x=241 y=299
file:release->menu dx=37 dy=1
menu:finalize success=false     ← no menu:start
```
vs a success at `dx=33`. Conclusion: not a threshold, a race — `manager.fail()` is terminal for the whole touch, so whether `swipeToMenu` survives depends on whether one more pointer move arrives. Also the 8pt window between `activeOffsetX(16)` and release at `dx > 24` where `swipeToMenu` is eligible but blocked.
